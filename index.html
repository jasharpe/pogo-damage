Pokémon GO damage formulas: PvP and raids/gyms

PvP damage is floor(0.5 × Power × Atk / Def × Charge × Effectiveness × STAB × Shadow × Purified) + 1. Atk includes a 1.3 bonus and the attack stat stage. Def includes the defense stat stage. Raid and gym damage is floor(0.5 × Power × Atk / Def × Effectiveness × Friendship × STAB × Weather × Shadow × Purified × Mega × Party × Remote + 1). Values are for game version 0.429.1 and the current game master.

Where each formula applies

  • PvP formula: Team Leader and NPC trainer battles, and Team GO Rocket battles. In these battles the game calculates damage on your device.
  • Online PvP (GO Battle League, friend battles): the server calculates damage and sends the results. The server probably uses the same formula, but this is not confirmed.
  • Raid and gym formula: raids and gym battles.

PvP formula

Atk    = CPM × (base Attack + Attack IV) × AttackStage × 1.3
Def    = CPM × (base Defense + Defense IV) × DefenseStage
Charge = 1 for a fast move
       = clamp(AttackerScore − DefenderScore, 0, 1) for a charged move
Damage = floor(0.5 × Power × Atk / Def × Charge × Effectiveness × STAB × Shadow × Purified) + 1

CPM CP multiplier for the Pokémon's level Level 40 = 0.7903
base Attack, base Defense species base stats per species
IV individual values 0–15
AttackStage, DefenseStage stat stage multiplier (attacker's attack stage, defender's defense stage) see the table below
1.3 PvP attack bonus, for fast and charged moves 1.3
Power PvP move power (the PvP value, not the raid value) per move
AttackerScore charged-move score 0–1
DefenderScore 1 if the defender uses a shield, else 0 0 or 1
Effectiveness type effectiveness, multiplied for each defender type 1.6, 1.0, 0.625 or 0.390625 per type
STAB same-type attack bonus 1.2
Shadow 1.2 for a shadow attacker; 1.2 more for a shadow defender (÷ 0.8333333) 1.0–1.44
Purified purified attacker against a shadow defender 1.0 (no effect)

Stat stages:

Stage −4 −3 −2 −1 0 +1 +2 +3 +4
Multiplier 0.5 0.5714286 0.6666667 0.8 1.0 1.25 1.5 1.75 2.0

Rules:

  • All calculations use 32-bit floats. Atk and Def are not rounded.
  • The game rounds down, then adds 1. So every hit does at least 1 damage.
  • A shielded charged move does exactly 1 damage.
  • A charged-move score of 0.5 gives half damage.
  • PvP damage has no weather, friendship, Mega boost, random variation or critical hits.
  • Stat stage changes from a move apply after that move's damage. They also apply when the defender uses a shield.
  • Energy is limited to 0–100.
  • Hidden Power's type depends on the Pokémon.
  • Aegislash Shield Forme as a defender: its final Def is replaced by 272. CPM, IVs, stat stages and bonuses have no effect on it.
  • Aegislash Shield Forme as an attacker: it gets 6 energy for each attack, not the move's normal energy.

NPC opponents:

Difficulty Charged-move score Shield
Easy 0.5–0.75 no effect
Medium 0.75–1.0 no effect
Hard 1.0 always shields

Worked example, Counter → Tyranitar:

Atk    = 0.7903 × (234 + 15) × 1.3 = 255.82
Def    = 0.7903 × (207 + 15)       = 175.447
Damage = floor(0.5 × 8 × 255.82 / 175.447 × 2.56 × 1.2) + 1
       = floor(17.917) + 1 = 18

Raid and gym formula

Atk    = CPM × (base Attack + Attack IV)
Def    = CPM × (base Defense + Defense IV)
Damage = floor(0.5 × Power × Atk / Def × Effectiveness × Friendship × STAB × Weather × Shadow × Purified × Mega × Party × Remote + 1)
Term Meaning Current value
CPM CP multiplier, including a Mega's CP multiplier while it is Mega Evolved per Pokémon
Power raid move power (not the PvP value) per move
Effectiveness type effectiveness 1.6, 1.0, 0.625 or 0.390625 per type
Friendship friendship bonus 1.03 / 1.05 / 1.07 / 1.10 / 1.12 (none = 1.0)
STAB same-type attack bonus 1.2
Weather weather boost for the move's type 1.2
Shadow 1.2 for a shadow attacker; 1.2 more for a shadow defender 1.0–1.44
Purified purified attacker against a shadow defender 1.0 (no effect)
Mega Mega boost, player attacks only 1.3 same type, 1.1 other type
Party party damage bonus, charged moves only 1.0 with no bonus
Remote remote raid multiplier 1.0 (no effect)

Rules:

  • All calculations use 32-bit floats.
  • The game adds 1, then rounds down. For normal values this gives the same result as the PvP rounding.
  • A dodged attack does 25% damage, minimum 1.
  • The defender gets energy equal to half the damage, rounded up.
  • Raid damage has no 1.3 bonus, no stat stages and no critical hits.
