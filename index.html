Pokémon GO damage formulas: PvP and raids/gyms

PvP damage is floor(0.5 × Power × Atk / Def × Charge × Effectiveness × STAB × Shadow × Purified) + 1. Atk includes a 1.3 bonus and the attack stat stage. Def includes the defense stat stage. Raid and gym damage is floor(0.5 × Power × Atk / Def × Effectiveness × Friendship × STAB × Weather × Shadow × Purified × Mega × Party × Remote + 1). Values are for game version 0.429.1 and the current game master.

Number types and order of operations:

  • Every intermediate value is a 32-bit float (float), not a double. Each multiplication or division rounds to 32-bit float before the next step.
  • Atk and Def stay floats. They are never rounded to whole numbers. Only base + IV is an integer sum, which is then converted to a float.
  • The final damage is an integer (int). It is not stored as a float.
  • PvP: Atk = ((CPM × (base + IV)) × stage) × 1.3 and Def = (CPM × (base + IV)) × stage × 1.0. Then ((((((Atk × Power) × Charge) × Effectiveness) × STAB) × Shadow) × Purified) / Def × 0.5, in exactly that order. The result is rounded down to an integer, and then the integer 1 is added.
  • Raid/gym: ((Atk × Power) / Def) × Effectiveness × Friendship × STAB × Weather × Shadow × Purified × Mega × Party × Remote × 0.5, left to right. Then the float 1.0 is added, and the result is rounded down to an integer. The order of the six terms from Effectiveness to Purified is not fully confirmed; it can change only the last bit of the float.
  • Because the steps round to 32-bit float in this order, a calculation in a different order or in double precision can give a different result when the value is very near a whole number.
  • The full calculation is in Reference code at the end.

Where each formula applies

  • PvP formula: Team Leader and NPC trainer battles, and Team GO Rocket battles. In these battles the game calculates damage on your device.
  • Online PvP (GO Battle League, friend battles): the server calculates damage and sends the results. The server probably uses the same formula, but this is not confirmed.
  • Raid and gym formula: raids and gym battles.

Rules:

  • All calculations use 32-bit floats. Atk and Def are not rounded.
  • The game rounds down, then adds 1. So every hit does at least 1 damage.
  • A shielded charged move does exactly 1 damage.
  • A charged-move score of 0.5 gives half damage.
  • PvP damage has no weather, friendship, Mega boost, random variation or critical hits.
  • Stat stage changes from a move apply after that move's damage. They also apply when the defender uses a shield.
  • Energy is limited to 0–100.
  • Hidden Power's type depends on the Pokémon.
  • Aegislash Shield Forme as a defender: its final Def is replaced by 272. CPM, IVs, stat stages and bonuses have no effect on it.
  • Aegislash Shield Forme as an attacker: it gets 6 energy for each attack, not the move's normal energy.

Reference code

C#-style code with the same operations, in the same order, with the same number types. float is a 32-bit float; every float operation rounds to 32-bit float. Floor rounds toward minus infinity.

PvP

int PvpDamage(Pokemon attacker, Pokemon defender, Move move,
              float attackerScore, float defenderScore, bool chargedMove)
{
    float bonus = chargedMove ? ChargeAttackBonus      // 1.3
                              : FastAttackBonus;       // 1.3
    float g     = chargedMove ? MinigameVariable       // 1.0
                              : 0f;

    float atk = attacker.Cpm * (float)(attacker.BaseAttack + attacker.IvAttack);    // integer sum, then float
    atk = atk * AttackStageMultiplier(attacker.AttackStage);                         // 1.0 at stage 0
    float def = defender.Cpm * (float)(defender.BaseDefense + defender.IvDefense);
    def = def * DefenseStageMultiplier(defender.DefenseStage);
    atk = atk * bonus;
    def = def * DefenseBonus;                                                        // 1.0

    if (defender.IsAegislashShieldForme) def = 272f;                                 // replaces the final Def

    float mg = 1f - g;
    if (g != 0f) {
        float s = attackerScore - DefenderMinigameMultiplier * defenderScore;         // DMM = 1.0
        s = Clamp(s, 0f, 1f);
        mg = mg + s * g;
    }

    float eff      = TypeEffectiveness(move.Type, defender.Type1, defender.Type2);   // per type, multiplied
    float stab     = (move.Type == attacker.Type1 || move.Type == attacker.Type2) ? 1.2f : 1f;
    float shadow   = (attacker.IsShadow ? 1.2f : 1f) / (defender.IsShadow ? 0.8333333f : 1f);
    float purified = (attacker.IsPurified && defender.IsShadow) ? 1.0f : 1f;

    float x = atk * move.Power;
    x = mg       * x;
    x = eff      * x;
    x = stab     * x;
    x = shadow   * x;
    x = purified * x;
    x = x / def;
    x = x * 0.5f;
    return (int)Floor(x) + 1;                                                        // integer result
}

Hidden Power: its type is (int)(Abs((float)((long)pokemonId % 16)) + 2f), where pokemonId is the Pokémon's unique 64-bit ID and % is a signed remainder. This gives 2–17 (Fighting to Dark). The same type is used for STAB.

Raid / gym

int RaidDamage(Pokemon attacker, Pokemon defender, Move move, Conditions cond, bool attackerIsBoss)
{
    float atk = attacker.Cpm * (float)(attacker.IvAttack + attacker.BaseAttack);    // integer sum, then float
    float def = defender.Cpm * (float)(defender.IvDefense + defender.BaseDefense);

    float eff      = TypeEffectiveness(move.Type, defender.Type1, defender.Type2);
    float friend   = FriendshipBonus(cond.FriendshipLevel);                          // 1.0 at level 0
    float stab     = (move.Type == attacker.Type1 || move.Type == attacker.Type2) ? 1.2f : 1f;
    float weather  = IsBoosted(cond.Weather, move.Type) ? 1.2f : 1f;
    float shadow   = (attacker.IsShadow ? 1.2f : 1f) / (defender.IsShadow ? 0.8333333f : 1f);
    float purified = (attacker.IsPurified && defender.IsShadow) ? 1.0f : 1f;
    float mega     = attackerIsBoss ? 1f : MegaBoost(attacker, move);                // 1.3 / 1.1 / 1.0
    float party    = attackerIsBoss ? 1f : PartyBonus(move);                         // charged moves only
    float remote   = cond.IsRemote ? RemoteDamageModifier : 1f;                      // 1.0

    float x = atk * move.Power;
    x = x / def;
    x = x * eff * friend * stab * weather * shadow * purified * mega * party * remote;   // left to right
    x = x * 0.5f;
    x = x + 1f;                                                                       // float add
    return (int)Floor(x);                                                             // integer result
}

// Applied after RaidDamage:
int ApplyModifiers(int dmg, long attackerFlat, long attackerPct, long defenderFlat, long defenderPct)
{
    float p = Max(0f, (float)(defenderPct + attackerPct) / 100f + 1f);
    long  f = Max(0L, attackerFlat + defenderFlat + dmg);
    return (int)(p * (float)f);                                                       // truncated toward zero
}
int Dodged(int dmg) => (int)Max(1f, (1f - 0.75f) * dmg);                             // 25 %, minimum 1
int DefenderEnergyGain(int dmg) => CeilToInt(0.5f * dmg);
