Pokémon GO damage formulas: PvP and raids/gyms

Damage formulas for Pokémon GO version 0.429.1 with the current game master. The code blocks below give each calculation step by step, with the number type of every value.

Where each formula applies

  • PvP formula: Team Leader and NPC trainer battles, and Team GO Rocket battles. In these battles the game calculates damage on your device.
  • Online PvP (GO Battle League, friend battles): the server calculates damage and sends the results. The server probably uses the same formula, but this is not confirmed.
  • Raid and gym formula: raids and gym battles.

PvP formula

// Number types: int = 32-bit integer, float = 32-bit float.
// The PvP calculation uses no double. Every float operation rounds its
// result to float before the next line. The lines run in this order.

// Step 1: attacker's Attack
int   attackSum = baseAttack + attackIV;            // integer add (species base + IV 0-15)
float atk       = attackerCpm * (float)attackSum;   // int -> float, then float multiply
atk             = atk * attackStageMultiplier;      // float; 1.0 at stage 0 (table below)

// Step 2: defender's Defense
int   defenseSum = baseDefense + defenseIV;         // integer add
float def        = defenderCpm * (float)defenseSum; // int -> float, then float multiply
def              = def * defenseStageMultiplier;    // float; 1.0 at stage 0

// Step 3: PvP bonuses (Atk and Def are never rounded to whole numbers)
atk = atk * 1.3f;                                   // attack bonus, fast and charged moves
def = def * 1.0f;                                   // defense bonus
if (defenderIsAegislashShieldForme) def = 272f;     // replaces the final Def

// Step 4: charged-move multiplier
float charge = 1.0f;                                // fast move
if (chargedMove) {
    float score = attackerScore - 1.0f * defenderScore;   // defenderScore: 1.0 with a shield, else 0
    if (score < 0f) score = 0f;
    if (score > 1f) score = 1f;
    charge = (1.0f - 1.0f) + score * 1.0f;          // = score
}

// Step 5: damage, in exactly this order
float x = atk * power;                              // power is a float
x = x * charge;
x = x * effectiveness;                              // float, product over the defender's types
x = x * stab;                                       // 1.2f or 1.0f
x = x * shadow;                                     // float: (1.2f or 1.0f) / (0.8333333f or 1.0f)
x = x * purified;                                   // 1.0f
x = x / def;
x = x * 0.5f;

// Step 6: result
int damage = (int)MathF.Floor(x) + 1;                // round down to int, then integer +1
                                                    // damage is an int; it is never stored as a float

Rules:

  • All calculations use 32-bit floats. Atk and Def are not rounded.
  • The game rounds down, then adds 1. So every hit does at least 1 damage.
  • A shielded charged move does exactly 1 damage.
  • A charged-move score of 0.5 gives half damage.
  • PvP damage has no weather, friendship, Mega boost, random variation or critical hits.
  • Stat stage changes from a move apply after that move's damage. They also apply when the defender uses a shield.
  • Energy is limited to 0–100.
  • Hidden Power's type depends on the Pokémon.
  • Aegislash Shield Forme as a defender: its final Def is replaced by 272. CPM, IVs, stat stages and bonuses have no effect on it.
  • Aegislash Shield Forme as an attacker: it gets 6 energy for each attack, not the move's normal energy.

NPC opponents:

Difficulty Charged-move score Shield
Easy 0.5–0.75 no effect
Medium 0.75–1.0 no effect
Hard 1.0 always shields

Raid and gym formula

// Number types: int = 32-bit integer, long = 64-bit integer, float = 32-bit float,
// double = 64-bit float. Every float operation rounds its result to float before
// the next line. The lines run in this order.

// Step 1: Attack and Defense (no bonus, no stat stages; never rounded to whole numbers)
int   attackSum  = attackIV + baseAttack;           // integer add
float atk        = attackerCpm * (float)attackSum;  // int -> float, then float multiply
int   defenseSum = defenseIV + baseDefense;         // integer add
float def        = defenderCpm * (float)defenseSum; // int -> float, then float multiply

// Step 2: multipliers (all float)
float effectiveness = ...;                          // product over the defender's types
float friendship    = ...;                          // 1.0f, or 1.03f to 1.12f
float stab          = ...;                          // 1.2f or 1.0f
float weather       = boosted ? (float)weatherBonus : 1.0f;   // the setting is a double (1.2), converted to float
float shadow        = ...;                          // (1.2f or 1.0f) / (0.8333333f or 1.0f)
float purified      = ...;                          // 1.0f
float mega          = ...;                          // 1.3f, 1.1f or 1.0f (player attacks only)
float party         = ...;                          // Max(0f, (float)partyPercent / 100f + 1f), charged moves only; partyPercent is a long
float remote        = ...;                          // 1.0f

// Step 3: damage, in exactly this order
float x = atk * power;                              // power is a float
x = x / def;
x = x * effectiveness;
x = x * friendship;                                 // the order of these six lines
x = x * stab;                                       // (effectiveness to purified) is not fully
x = x * weather;                                    // confirmed; it can change only the last
x = x * shadow;                                     // bit of the float
x = x * purified;
x = x * mega;
x = x * party;
x = x * remote;
x = x * 0.5f;
x = x + 1.0f;                                       // float add, before rounding

// Step 4: result
int damage = (int)MathF.Floor(x);                    // round down to int; damage is an int

// Step 5: after the formula (raids and gyms)
float pct  = Math.Max(0f, (float)(defenderPct + attackerPct) / 100f + 1f);   // the two percentages are longs
long  flat = Math.Max(0L, attackerFlat + defenderFlat + damage);             // long add
damage     = (int)(pct * (float)flat);              // long -> float, float multiply, then truncate to int
if (dodged) damage = (int)Math.Max(1f, (1f - 0.75f) * damage);   // int -> float, then truncate; minimum 1
int defenderEnergy = (int)MathF.Ceiling(0.5f * damage);           // round up to int

Reference code

The game's own damage code from version 0.429.1, written out as C#. Some names are short codes (for example bnai, bvwf) because the app hides its private names. f32(x) marks a rounding of x to a 32-bit float; every float operation rounds to 32-bit float.

PvP: damage (bnai)

int GetAttackDamage(CombatPokemonProto A, CombatPokemonProto D, int moveId,
                    float atkMult, float atkScore = 0, float defScore = 0, float g = 0)
{
    IPokemonSettings aS = gm.Get_PokemonSettingsWithOverrides(A);
    IPokemonSettings dS = gm.Get_PokemonSettingsWithOverrides(D);
    var move = gm.MaybeGetByKey<CombatMoveSettingsProto>((HoloPokemonMove)moveId);
    if (move == null) return 0;
    var stageCfg = gm.MaybeGet<CombatStatStageSettingsProto>();

    float atk = f32(f32(A.CpMultiplier * (float)(A.IndividualAttack + aS.Stats.BaseAttack))
                    * A.AttackBuffMultiplier(stageCfg));
    float def = f32(f32(D.CpMultiplier * (float)(D.IndividualDefense + dS.Stats.BaseDefense))
                    * D.DefenseBuffMultiplier(stageCfg));
    float defBonus = Settings?.DefenseBonusMultiplier ?? 1f;
    atk = f32(atk * atkMult);                                           // 1.3 fast / 1.3 charged
    def = f32(def * defBonus);                                          // 1.0

    var ibfc = gm.GetIBFCOverrides();                                   // IBFC_LIGHTWEIGHT_SETTINGS
    if (ibfc != null) {
        if (A.PokedexId == 681 /*AEGISLASH*/ && A.PokemonDisplay.Form == 2639 /*AEGISLASH_SHIELD*/
            && A.Move1 == moveId) {                                     // fast move only
            float o = ibfc.DefaultAttackOverride;
            if (o < 0)        atk = 0f;
            else if (o != 0)  atk = (float)(int)o;                      // replaces the full effective attack
            else if (ibfc.DefaultAttackMultiplier != 0)
                              atk = f32(atk * (float)(int)ibfc.DefaultAttackMultiplier);   // multiplier truncated to int
        }
        if (D.PokedexId == 681 && D.PokemonDisplay.Form == 2639) {
            float o = ibfc.DefaultDefenseOverride;
            if (o != 0)       def = (float)(int)o;                      // replaces the full effective defense
            else if (ibfc.DefaultDefenseMultiplier != 0)
                              def = f32(def * (float)(int)ibfc.DefaultDefenseMultiplier);
        }
    }

    HoloPokemonType t = (move.UniqueId == 281 /*HIDDEN_POWER_FAST*/)
        ? (int)(Mathf.Abs((float)((long)A.PokemonId % 16)) + 2f)        // 2..17 = FIGHTING..DARK
        : move.Type;

    float mg = f32(1f - g);
    if (!Mathf.Approximately(g, 0f)) {
        float s = f32(atkScore - f32((Settings?.DefenderMinigameMultiplier ?? 1f) * defScore));
        s = (s < 0) ? 0f : (s > 1f ? 1f : s);                           // Clamp01
        mg = f32(mg + f32(s * g));
    }

    float eff  = gm.Get_TypeEffectiveness(t, dS.Type1, dS.Type2);
    float stab = GetSameTypeAttackMultiplier(aS, move, A);              // see GetSameTypeAttackMultiplier below
    float shad = shadowHelper.GetShadowDamageModifier(A, D, Settings);
    float pur  = shadowHelper.GetPurifiedDamageModifier(A, D, Settings);

    float x = f32(atk * move.Power);
    x = f32(mg   * x);
    x = f32(eff  * x);
    x = f32(stab * x);
    x = f32(shad * x);
    x = f32(pur  * x);
    x = f32(x / def);
    x = f32(x * 0.5f);
    return (floor(x) == +inf) ? int.MinValue + 1 : (int)floor(x) + 1;
}

PvP: stat stage multiplier

float AttackBuffMultiplier(CombatPokemonProto p, CombatStatStageSettingsProto s) {
    if (p.AttackStatStage == 0) return 1f;                  // the table is not read
    int i = p.AttackStatStage - s.MinimumStatStage;         // stage + 4
    return s.AttackBuffMultiplier[i];
}

PvP: shadow and purified

float GetShadowDamageModifier(A, D, S) {
    float a = (A.Display.Alignment == SHADOW && S.ShadowPokemonAttackBonusMultiplier  > 0) ? S.ShadowPokemonAttackBonusMultiplier  : 1f;
    float d = (D.Display.Alignment == SHADOW && S.ShadowPokemonDefenseBonusMultiplier > 0) ? S.ShadowPokemonDefenseBonusMultiplier : 1f;
    return f32(a / d);                       // a shadow defender gets 1/0.8333333 = 1.2000000x damage
}
float GetPurifiedDamageModifier(A, D, S) {
    return (A.Display.Alignment == PURIFIED && D.Display.Alignment == SHADOW
            && S.PurifiedPokemonAttackMultiplierVsShadow > 0) ? S.PurifiedPokemonAttackMultiplierVsShadow : 1f;
}

Raid / gym: damage (CalculateDamage)

int CalculateDamage(IPokemonBattleData attacker, IPokemonBattleData target,
                    MoveSettingsProto move, IBattleConditions cond,
                    out AttackOutcome outcome, bool attackerIsBattleEnemy)
{
    if (attacker == null || target == null || move == null) { outcome = Missed(4); return 0; }
    var aS = attacker.GetPokemonSettings(gm, useDisplay:true);
    var dS = target  .GetPokemonSettings(gm, true);
    if (aS == null || dS == null) { outcome = 4; return 0; }

    int   baseAtk = aS.Stats.BaseAttack;
    int   ivAtk   = attacker.IndividualAttack;
    float cpmA    = attacker.CombatCpMultiplier;
    int   baseDef = dS.Stats.BaseDefense;
    int   ivDef   = target.IndividualDefense;
    float cpmD    = target.CombatCpMultiplier;

    HoloPokemonType t = move.Type;
    float eff     = gm.Get_TypeEffectiveness(t, dS);
    float stab    = bvwf(t, aS);
    float weather = bvwh(t, cond.Weather);
    float friend  = bvwi(cond.HighestFriendshipLevelMilestone);
    var   gbs     = gm.MaybeGet<GymBattleSettingsProto>();
    float shadow  = shadowHelper.GetShadowDamageModifier (attacker.PokemonDisplay, target.PokemonDisplay, gbs);
    float purif   = shadowHelper.GetPurifiedDamageModifier(attacker.PokemonDisplay, target.PokemonDisplay, gbs);

    float remote = 1f;
    if (cond.IsRemote)
        remote = gm.MaybeGet<RaidClientSettingsProto>().RemoteDamageModifier;
    float mega = 1f, pct = 1f;
    if (!attackerIsBattleEnemy) {
        if (cond.CurrentBattleFrame != null) mega = bvvy(attacker, move, cond.CurrentBattleFrame);
        if (cond.CurrentBattleFrame != null) pct  = bvvz(move, cond.CurrentBattleFrame);
    }

    float A = cpmA * (float)(ivAtk + baseAtk);      // float32
    float D = cpmD * (float)(ivDef + baseDef);
    float x = A * move.Power;
    x = x / D;
    x = x * eff * friend * stab * weather * shadow * purif * mega * pct * remote;   // left to right, float32
    x = x * 0.5f;
    x = x + 1f;
    int dmg = (int)floorf(x);
    outcome = eff > 1 ? SuperEffective(3) : eff < 1 ? NotVeryEffective(1) : Normal(2);
    return dmg;
}

Raid / gym: helpers

float bvwf(HoloPokemonType t, IPokemonSettings aS)          // STAB
    => (t == aS.Type1 || t == aS.Type2) ? gm.MaybeGet<GymBattleSettingsProto>().SameTypeAttackBonusMultiplier : 1f;

float bvwh(HoloPokemonType t, Weather weather)                // weather boost
    => gm.IsPokemonMoveWeatherBoosted(weather, t) ? (float)gm.MaybeGet<WeatherBonusProto>().AttackBonusMultiplier : 1f;

float bvwi(int level)                                         // friendship
    => level != 0 ? GetFriendshipLevelMilestoneSettings(gm, level).AttackBonusPercentage : 1f;   // key "FRIENDSHIP_LEVEL_{n}"

float bvvy(attacker, move, frame)                             // Mega boost
    => frame.GetMegaBoostType(attacker, move) switch {
           2 => MegaEvoSettings.AttackBoostFromMegaSameType,
           1 => MegaEvoSettings.AttackBoostFromMegaDifferentType,
           _ => 1f };

float bvvz(move, frame)                                       // party damage bonus, charged moves only
    => move.EnergyDelta < 0 ? Math.Max(0f, (float)frame.LocalPlayer.DamageDealtPercentageModifier / 100f + 1f) : 1f;

float CombatCpMultiplier                                      // PokemonProto
    => (display.IsMegaEvolved && tempEvoCpMultiplier != 0) ? tempEvoCpMultiplier : cpMultiplier + additionalCpMultiplier;

Raid / gym: party and flat modifiers (applied after CalculateDamage)

int d   = this.CalculateDamage(attacker, target, move, cond, out outcome, attackerIsBattleEnemy);
float p = Math.Max(0f, (float)(targetDamageTakenPct + attackerDamageDealtPct) / 100f + 1f);     // long sum -> float
long  f = Math.Max(0L, attackerDamageDealtFlat + targetDamageTakenFlat + d);
return (int)(p * (float)f);

After this, a dodged attack does (int)Math.Max(1f, (1f - DodgeDamageReductionPercent) * dmg) (DodgeDamageReductionPercent = 0.75), and the defender gains Mathf.CeilToInt(EnergyDeltaPerHealthLost * dmg) energy (EnergyDeltaPerHealthLost = 0.5).
